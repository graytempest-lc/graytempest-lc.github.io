Alpine 的 SSH 服务需修补密码认证绕过

OpenSSH 10.6p2 为使用 musl 且未启用 PAM 的部分 Linux 系统加入安全修复。Alpine 已提供回补包；风险还取决于密码登录开启及特定账户配置，并非所有容器都受影响。

运行 sshd 的 Alpine 主机应按官方公告检查配置，更新 openssh 后必须重启 sshd，仅升级软件包不会替换运行中的服务。不运行 sshd 的容器不受此问题影响。

11月5日 · 安全更新Alpine 官方安全公告OpenSSH 发布说明

Bionic 1.2.0 更新本地引擎与会话分叉

新版包含 Apple Silicon 的 oMLX 0.1.0 引擎与 llama.cpp 2.67.0 扩展包，加快大型项目文件建议和长侧边聊天加载，并修复 Flint 模型模板解析。

分叉会话会继承已有批准，使用前应了解权限延续方式；2.67.0 是 LM Studio 扩展包版本，不是上游 llama.cpp 版本。

11月5日 · 发布LM Studio 发布说明

llama.cpp 调整 Metal 上部分 LoRA 的计算路径

b12138 预发布将 32 ≤ K < 64 的矩阵乘法改走 mul_mm，并加入 bf16 × bf16 内核。对应改动于 11 月 5 日合并，晚于此前报道的 0.9.0。

rank 32／48 LoRA 用户可重点回归预填充性能；这是特定 Metal 路径优化，不能推断所有模型或设备都会提速。

11月5日 · 预发布llama.cpp 发布说明改动与测试范围

GitHub PR 概览把合并阻碍移到顶部

新的 Overview 页面进入自愿启用的公开预览，在顶部汇集合并状态、检查与后续动作，并支持未解决讨论过滤和最新评论优先排序。

处理大量人工或代理生成的 PR 时，可更快找到待办；预览分批推出至周末，也可切回经典页面。

11月5日 · 公共预览GitHub 官方说明

IBM、ORNL 与 AMD 联建量子纠错研究平台

新平台把包括 120 量子比特 Nighthawk 的 IBM 量子计算机与 ORNL 的 Umbra 高性能计算系统协同部署，后者使用 AMD MI355X GPU 和第五代 EPYC CPU。

研究重点包括纠错解码和软件编排，体现经典计算与量子控制的协同需求。这是研究平台发布，不代表通用容错量子计算已经实现。

11月5日 · 研究平台发布IBM 官方公告

GitHub 密钥扫描扩展检测并减少误报

GitHub 新增 Starlink Public API v2 密钥检测与 SpaceX 合作方通知，并改进 AWS、Google、OpenVSX 等检测器的误报过滤。

开发者可减少占位值和无关 UUID 带来的告警噪声；公开仓库中命中的合作方密钥会通知发行方，扫描仍不能替代泄漏后的吊销与轮换。

11月5日 · 功能更新GitHub 官方变更日志

Android Chrome 157 更新，158 开始小范围稳定渠道测试

Chrome 157.0.8103.46 开始向 Android 用户分批推送，包含对应桌面版的安全修复；158.0.8127.22 同日进入面向少量用户的 Early Stable。

移动网页开发者可提前做 158 兼容性回归，但不要把 Early Stable 当成所有用户已升级。157 的更新也可能需要数日才能在 Google Play 可见。

11月5日 · 分批发布Chrome 157 官方公告Chrome 158 Early Stable 公告

ZenDNN 6.1.0 扩充 CPU 推理内核

AMD 更新 ZenDNN，新增多种量化矩阵乘内核、GQA 与滑动窗口 Flash Attention、routed-MoE API，并默认启用原地权重缓存。

在 AMD CPU 上自托管模型的开发者可复测量化、注意力和 MoE 工作负载，同时观察缓存内存占用；实际收益仍取决于模型与机器配置。

11月4日 · 版本发布 · 近7日补充AMD 官方发布说明

Langfuse AI Gateway 开放费用追踪测试

AI Gateway 进入公开 beta，可通过更换 base URL 和 API key 接入 OpenAI 或 Anthropic 原生接口，自动记录调用并按用户、密钥和模型统计费用。

适合小团队集中管理编码代理的上游密钥与成本；它不转换不同 API 格式，也不意味着请求在本地处理。

11月4日 · 公开测试 · 近7日补充Langfuse 官方说明

Kinference 为自托管推理加入策略控制

Buoyant 发布 Apache v2 开源项目 Kinference，在 vLLM 等引擎之上提供 Kubernetes 策略路由、token 限流、租户用量追踪和缓存感知负载均衡。

适合运营多 GPU、多个模型的团队评估；它不是单机推理的必需组件，特定工作负载的厂商测速不能当作通用提速保证。

11月4日 · 开源发布 · 近7日补充Buoyant 官方介绍

Firefox 159.0.1 修复通行密钥与 Linux WebGL 问题

更新修复相关站点共享通行密钥时登录失败、Linux 部分 WebGL 页面红蓝色颠倒，并修补一项高危布局边界条件漏洞。

开发登录流程、网页视频特效或 WebGL 应用时，可升级浏览器后重跑回归，避免把浏览器问题误判为业务缺陷；安全公告未声称该漏洞已遭在野利用。

11月3日 · 修复发布 · 近7日补充Firefox 官方发布说明Mozilla 安全公告

Dependabot 开始维护智能体技能依赖

Dependabot 可为 apm.yml 中受支持的 git 依赖提交版本更新 PR，并在存在时重建 apm.lock.yaml。github.com 所有方案均已可用。

这把技能、提示和指令纳入版本维护流程，但只支持版本更新，不是安全更新；新指令与技能仍需审查后合并。

11月3日 · 正式可用 · 近7日补充GitHub 官方说明

GitHub Desktop 逐步采用自动续期的短期令牌

GitHub Desktop 3.6.10 及更新版本开始向符合条件的账号发放短期认证令牌，并为 Git 和 API 操作自动刷新。

可缩短泄漏令牌的有效窗口，但旧会话不会因升级自动迁移；需在功能覆盖后登录才会签发新令牌，此轮不包含 GitHub Enterprise Server。

11月2日 · 分批上线 · 近7日补充GitHub 官方说明

离线 RAG 知识包签名，不能证明向量与原文一致

Signed but Steerable 研究指出，签名可验证知识包发布者，却不能保证预计算向量忠实对应文本；研究测试了容差校验与压缩向量索引的可操纵性。

维护本地知识库时应单独检查文本与向量的绑定关系。论文提出规范化量化码校验方案，但结果来自有限语料、模型和硬件的受控实验，仍属预印本。

11月4日 · 预印本 · 近7日补充arXiv 原始论文

逐轮候选动作筛选，为长任务智能体提供另一种提效办法

一项预印本让生成模型每轮给出多个候选动作，再由选择模型挑选一个执行；在长流程终端任务中，研究报告准确性和重复尝试的一致性改善。

开放权重模型也可尝试“先比较再执行”的代理结构；收益伴随更多生成与选择调用，不能当作免费提速，终端基准结果也不能外推到所有应用。

11月4日 · 预印本 · 近7日补充arXiv 原始论文
