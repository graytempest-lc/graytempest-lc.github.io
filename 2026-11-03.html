Linux 宿主内核漏洞需优先排查

Red Hat 更新 CVE-2026-98432 指引：IPv4 TCP 处理存在可被远程未认证攻击者利用的释放后使用漏洞。

RHEL、OpenShift 管理者应核查受影响版本并更新内核；过滤特定报文只是临时缓解，不能替代修补。

11月2日 · 指引更新Red Hat 官方公告

GitHub 高风险 PR 工作流限制延期

公有仓库 pull_request_target 默认封禁改至12月2日；11月9日、16日16:00–18:00 UTC先进行两次临时执行测试。

维护者应检查受影响工作流，避免届时突然失败；私有、内部仓库及GHES不受影响。

11月2日 · 公告GitHub 变更说明

LongCat-2.5 API 开放使用

官方更新日志列出原生视觉理解、复杂代码库和长程工程任务支持，并提供Claude Code、Codex等接入方式。

编程Agent多了一个可测试后端，实际可靠性仍需用自己的项目验证；这里确认的是API可用，并非开放权重。

11月2日 · 发布LongCat 官方日志

vLLM 新候选版改变 CUDA 包支持

v0.33.0rc3加入模型与推测解码改进，CUDA发行包转向13.0、不再提供12.9包，ROCm默认版本也升级。

自建推理服务应先核查驱动、镜像和依赖；虽然页面标题写0.33.0，此次标签仍为rc3，不按稳定版推荐升级。

11月2日 · 预发布标签vLLM 发布说明

MinerU 修正 PDF 公式混排

4.1.4改进行内公式识别与失败回退，修正普通美元符号被误判成公式、额外转义等问题，同时提高DocVortex最低版本。

做论文解析、知识库导入和RAG预处理时，可重点回归含公式的混合段落。

11月2日 · 发布MinerU 发布说明

LangChain 修复消息对象被意外修改

Core 1.7.4修正Anthropic消息转换器修改原始content的问题，对复用消息对象、回放会话的应用尤其有用。

公告还提醒，后续core 1.8与langchain 1.5将停止支持Python 3.10，旧环境应提前安排迁移。

11月2日 · 发布LangChain 发布说明

xAI 旧图像模型切换正式生效

grok-imagine-image-quality请求现由image-2.0的quality=low处理，接口结构不变。

旧程序仍能返回图片，不代表生成效果完全相同；使用该别名的开发者应检查质量参数并重跑视觉回归。

11月2日 · 此前公告生效xAI 迁移指南

Antigravity 加入 Google Cloud 开发插件

新插件将Google实时开发文档、按需技能发现及云资源操作约束放进一个安装入口。

对云应用开发者，价值是减少过时SDK或无效命令的猜测；官方称涉及计费API与基础设施修改会要求同意，但仍应自行审查实际操作。

11月3日 · 发布Google Cloud 官方公告

Cloudflare 公开 DNS 增量构建优化

新的planner选择最小安全构建，并合并同一区域的待办变更。Cloudflare报告全量构建约减少40%、峰值内存减少85%，为大型配置系统提供增量更新案例。

这里改善的是变更构建延迟，不是DNS查询延迟；数据来自厂商报告。

11月2日 · 工程复盘Cloudflare 技术原文

GitHub 风险评估显示仓库保护缺口

代码与密钥风险评估新增“受保护／未受保护仓库”信息，方便组织判断发现漏洞的仓库是否已有安全工具覆盖。

Team和Enterprise Cloud可用；维护多个项目时，比只看告警总数更容易定位漏配的保护措施。

11月2日 · 已上线GitHub 官方说明

Workload Map 统一描述 AI 集群任务

NVIDIA展示如何用YAML统一描述JobSet、Ray等Kubernetes任务，让调度和管理工具复用同一套结构定义，减少逐框架编写解析器。

该Apache 2.0组件已用于Run:ai生产环境；它不是当天首次发布，也不是单机推理加速工具。

11月2日 · 技术介绍NVIDIA 技术原文

PyTorch 2.15 扩充本地推理后端

Apple Silicon新增FP8及公开Stream接口，CUDA默认包转向13.2并提供13.4选项，torch.compile支持Python 3.15。

Mac与多种GPU开发环境都有可用更新，但部分新API仍不稳定，官方性能数字也不等于你的模型收益。

10月28日 · 发布 · 近7日补充PyTorch 完整发布文章

GitHub Webhook 增加出口 IP 网段

Meta API的hooks字段新增三个网段。

自建CI、机器人或通知服务若使用静态IP白名单，需要更新以避免漏收Webhook；已经自动同步Meta API的服务无需手工维护同一份列表。

10月29日 · 发布 · 近7日补充GitHub 官方公告

研究提醒：工具日志也能暴露用户画像

PrivacyTrace用1,000个合成画像、4,000条Agent轨迹研究MCP隐私：工具参数和返回值让画像推断明显强于盲猜。

对Agent开发者，日志内容、保留时间与跨会话关联都值得检查；这是合成实验，防护方案尚未验证有效。

10月30日 · 预印本 · 近7日补充论文原文

AI 安全评分可能被数据集“提示答案”

研究发现，简单词频分类器在一套代码后门基准上超过20/24个开放权重监控模型，部分优势来自作者风格和标签问题。

做代码审查Agent评测时，应加入简单基线并验证后门确实有效；结果不等于证明所有监控模型都在作弊。
