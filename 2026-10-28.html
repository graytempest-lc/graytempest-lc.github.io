LFM3：面向本地任务的轻量模型

Liquid AI 发布首批约 2B 参数模型，覆盖文本、视觉、音频、全模态与决策任务。

分类、信息提取和语音处理，多了面向专门任务的轻量选择。实际部署仍需确认模型许可、推理框架与设备支持。

Windows App SDK 2.6.4 简化语言模型 API 接入

使用新版本，无需再解锁语言模型的 Limited Access Feature；旧版本的 LAF 要求仍保留。更新还修复了应用关闭与 WebView2 焦点处理等场景中的崩溃。

接入前仍要核对目标 Windows 版本与硬件要求。

10 月 27 日发布Microsoft 发布说明

共享一张 GPU， 为每个服务划定显存边界

NVIDIA 介绍 CUDA 13.4 配合 GPU Fractioning Operator 与 KAI Scheduler，在 Kubernetes 中设置显存保底、上限与弹性配额。超额分配会失败，而非继续挤占其他服务。

适合多推理服务共卡；SM-sharing 仍共享错误域，不等同于 MIG 硬件隔离。

10 月 27 日技术文章NVIDIA 技术原文

Genie 4 为实时生成世界 加入声音与对话

DeepMind 展示带原生环境音、对话及文字修改能力的交互场景。目前仅面向可信测试者，Ultra 与 API 开放仍属后续计划。

物体一致性、物理与长期稳定性仍有限，暂不能当作可本地部署的游戏引擎。

10 月 27 日公布DeepMind 原文

MoE 推理优化，别只看峰值跑分

NVIDIA 展示 DGX Spark 上结合 MoE 内核、FP8 输出与多词元预测（MTP）的优化：Ling 3.0 flash 的 GSM8K 解码吞吐提升 42.5%，合成负载提升 185.1%。

这是厂商特定配置结果。MTP 模块共享配置不当也可能变慢；复测要看真实任务耗时、首词延迟和接受率。

10 月 27 日技术文章MoE 优化原文

MotionBricks 更新角色动作工具

MotionBricks 更新支持 SOMA 人体模型，提供权重、ONNX 模型及 Newton 交互参考，可探索由目标姿态驱动的连续行走、坐下与拾取动作。

仍是研究代码。演示中的 Unreal Engine 集成未包含在仓库中；官方 Windows / Linux RTX 4090 测试不代表所有设备表现。
