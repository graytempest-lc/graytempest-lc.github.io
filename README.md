# L星团快讯

计算机领域简报、公开文章与文件的独立静态发布站。

## 发布范围
- 整理并核验来源的计算机领域简报与公开文章。
- 仅发布明确获准公开的文件。
- 不发布私人资料、聊天记录、凭据或未授权项目内容。

## 维护
- `index.html`：首页及首批内容。
- `style.css`：响应式样式，含键盘焦点与减少动态效果支持。
- 不依赖构建工具、外部字体、JavaScript 或第三方统计。
- GitHub Pages 使用 main 分支根目录；`.nojekyll` 禁用 Jekyll 处理。

正式简报与下载文件尚未发布。没有虚构新闻、示例下载或未验证结果。
