## Sol3 首页月历维护

首页现在是完整月历加最新日报，不能再直接用日报覆盖 `index.html`。
新增或修改公开日报后，运行 `node tools/build-calendar.mjs`，再提交生成的 `index.html`、`sol3/news-data.mjs` 和 `sol3/calendar-data.mjs`。脚本读取现有日期文件并保留全部历史；不联网、不引入依赖。先读取最新远端再生成，避免覆盖并行发布。

月历按东八区民用日显示。2026 年中国大陆放假/调休来自国办发明电〔2025〕7号，新闻按本站日报刊载日归档，非事件发生日。农历和节气目前仅核对 2026 年，其他年份不套旧数据。新增年份必须先核验节假日、农历及天文模型，不能仅放宽范围。

黄历是本地已核原典的部分实现，最终宜、忌始终为空，不是完整择日建议，也未声称与百度一致。节气时刻来自 MIT 许可的 Astronomy Engine 2.1.19 本地计算，标为模型估算；源码与许可位于 `sol3/vendor/`。交节日仍保留前后两个日级条件，估算时刻不使未核宜忌变成确定结论。

核验时至少检查：全部历史日报内容不变、最新正文完整、月份切换及手机布局、元旦/春节/国庆调休、交节前后、无日报日期、越界年份、键盘导航和所有本地链接。
